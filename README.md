# Sze Ying Choong — Portfolio

A responsive, static portfolio website prepared using the résumé details available in the conversation.

## Preview locally
Open `index.html` in a browser. No build tools or dependencies are required.

## Publish to GitHub Pages
1. Download and extract this ZIP.
2. Upload the **contents** of the extracted folder to the root of `szeying-code/portfolio` (not the enclosing folder).
3. Commit the changes to the branch configured for GitHub Pages.
4. In the repository, check **Settings → Pages** to confirm the publishing branch and folder.

## Important content check
The site includes the education, roles, research topic and skills mentioned in the résumé summary provided in the conversation. Some detailed responsibilities, project outcomes, dates beyond those listed, contact details and external profile URLs were not available, so they have not been invented. Review the content against the full résumé before publishing.

https://szeying-code.github.io/resume/
